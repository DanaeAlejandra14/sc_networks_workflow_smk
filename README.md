# sc_networks_workflow_smk

Snakemake pipeline that builds gene regulatory networks from single-nucleus RNA-seq
(ROSMAP, DLPFC). For each phenotype and cell type it integrates the data, subsamples cells to
equal numbers across phenotypes, builds metacells with SuperCell, infers networks with
ARACNe-AP and (optionally) compares networks built with different SuperCell gammas.

Workflow overview:

```
demultiplex -> annotate -> split by cell type -> Harmony integration -> subsample to the
minimum per phenotype -> SuperCell metacells -> ARACNe-AP networks -> network analysis
```

Phenotypes: `control`, `MCI`, `AD-NC_ASYM`, `AD-NC_SYM`.

## Repository structure

- `config/config.yaml`: all pipeline parameters. `config/samples.tsv`: input samples.
- `data/`: raw count matrices per sample (pipeline input, listed in `config/samples.tsv`).
- `resources/`: reference resources and auxiliary tools (not sample-specific).
- `workflow/`: `Snakefile`, `scripts/` and `envs/` (one conda environment per group of rules).
- `results/` and `logs/`: generated by the pipeline (not tracked by Git).


## Requirements

- [Snakemake](https://snakemake.readthedocs.io) and conda/mamba: `<install instructions>`.
- Each rule creates its own conda environment from `workflow/envs/` when you run with `--use-conda`.
  This includes Java for ARACNe (`workflow/envs/aracne.yaml`), so you do **not** need to install
  Java manually to run the pipeline.
- The ARACNe-AP JAR (see below), which is **not** included in this repository.

## ARACNe-AP (`aracne.jar`)

The network inference steps use **ARACNe-AP** (Lachmann et al., *Bioinformatics*, 2016), a Java
implementation of ARACNe with adaptive partitioning. Each user must obtain the JAR and place it at:

```
resources/tools/aracne.jar
```

This path is set in `config/config.yaml` (`aracne.jar`). Note the lowercase file name.

### Build from source

Building is a one-time step. It needs a JDK (newer than 1.8) and Apache Ant, both provided by
`workflow/envs/aracne.yaml` (OpenJDK 11 and Ant):


```bash
# 1. Create the environment (Java + Ant) and activate it
conda env create -f workflow/envs/aracne.yaml
conda activate aracne

# 2. Go to the tools folder (from the project root; create it if needed)
mkdir -p resources/tools
cd resources/tools

# 3. Download and build ARACNe-AP
git clone https://github.com/califano-lab/ARACNe-AP.git
cd ARACNe-AP
ant main

# 4. Copy the JAR where the pipeline expects it and go back to the project root
cp dist/aracne.jar ../aracne.jar
cd ../../..

# 5.Check the installation

From the project root:

~/sc_networks_workflow_smk$

```bash
ls -lh resources/tools/aracne.jar

java -Xmx2G -jar resources/tools/aracne.jar \
  -e resources/tools/ARACNe-AP/test/matrix.txt \
  -o /tmp/aracne_test \
  --tfs resources/tools/ARACNe-AP/test/tfs.txt \
  --pvalue 1E-8 --seed 1 --calculateThreshold

ls /tmp/aracne_test

It should print `MI threshold: ...` and create `miThreshold_p1E-8_samples200.txt`.
```

## Snakemake environment

The pipeline is run with Snakemake, which is installed in its own conda environment. Rules that need
other software (R, Java, Python tools) create their own environments automatically from
`workflow/envs/` when you run with `--use-conda`.

Create the environment once (from the project root) and activate it every time you work on the
pipeline:

```bash
conda env create -f workflow/envs/snakemake.yaml
conda activate snakemake
```
## How to run it

Run all commands from the project root, with the `snakemake` environment active.

### 1. Dry run (shows what would be executed, runs nothing)

```bash
snakemake --until aracne_consolidate --use-conda --cores 4 \
  --resources mem_gb=10  -n
```

### 2. Run

```bash
snakemake --until aracne_consolidate --use-conda --cores 4 \
  --resources mem_gb=10 
```
