# sc_networks_workflow_smk

Snakemake pipeline that builds gene regulatory networks from single-nucleus RNA-seq
(ROSMAP, DLPFC). For each phenotype and cell type it integrates the data, subsamples cells to
equal numbers across phenotypes, builds metacells with SuperCell, infers networks with
ARACNe-AP and (optionally) compares networks built with different SuperCell gammas.

Workflow overview:

```
demultiplex -> annotate -> split by cell type -> Harmony integration -> subsample to the
minimum per phenotype -> SuperCell metacells -> ARACNe-AP networks -> network analysis
```

Phenotypes: `control`, `MCI`, `AD-NC_ASYM`, `AD-NC_SYM`.

## Repository structure

- `config/config.yaml`: all pipeline parameters. `config/samples.tsv`: input samples.
- `data/`: raw count matrices per sample (pipeline input, listed in `config/samples.tsv`).
- `resources/`: reference resources and auxiliary tools (not sample-specific).
- `workflow/`: `Snakefile`, `scripts/` and `envs/` (one conda environment per group of rules).
- `results/` and `logs/`: generated by the pipeline (not tracked by Git).

## Requirements

- [Snakemake](https://snakemake.readthedocs.io) and conda/mamba: `<install instructions>`.
- Each rule creates its own conda environment from `workflow/envs/` when you run with `--use-conda`.
  This includes Java for ARACNe (`workflow/envs/aracne.yaml`), so you do **not** need to install
  Java manually to run the pipeline.
- The ARACNe-AP JAR (see below), which is **not** included in this repository.

## ARACNe-AP (`aracne.jar`)

The network inference steps use **ARACNe-AP** (Lachmann et al., *Bioinformatics*, 2016), a Java
implementation of ARACNe with adaptive partitioning. Each user must obtain the JAR and place it at:

```
resources/tools/aracne.jar
```

This path is set in `config/config.yaml` (`aracne.jar`). Note the lowercase file name.

### Build from source

Building is a one-time step. It needs a JDK (newer than 1.8) and Apache Ant, both provided by
`workflow/envs/aracne.yaml` (OpenJDK 11 and Ant):


```bash
# 1. Create the environment (Java + Ant) and activate it
conda env create -f workflow/envs/aracne.yaml
conda activate aracne

# 2. Go to the tools folder (from the project root; create it if needed)
mkdir -p resources/tools
cd resources/tools

# 3. Download and build ARACNe-AP
git clone https://github.com/califano-lab/ARACNe-AP.git
cd ARACNe-AP
ant main

# 4. Copy the JAR where the pipeline expects it and go back to the project root
cp dist/aracne.jar ../aracne.jar
cd ../../..

```

Check the installation from the project root:

```bash
ls -lh resources/tools/aracne.jar

java -Xmx2G -jar resources/tools/aracne.jar \
  -e resources/tools/ARACNe-AP/test/matrix.txt \
  -o /tmp/aracne_test \
  --tfs resources/tools/ARACNe-AP/test/tfs.txt \
  --pvalue 1E-8 --seed 1 --calculateThreshold

ls /tmp/aracne_test
```

It should print `MI threshold: ...` and create `miThreshold_p1E-8_samples200.txt`.

## ARACNe networks: current setup

Networks are built for the 4 phenotypes x Astrocyte x SuperCell gamma 60, 70 and 80
(12 networks; ~522, 448 and 392 metacells). Main choices, all set in `config/config.yaml`:

- **Same cells per phenotype:** every phenotype is subsampled to the smallest one
  (`subsample`; Astrocyte: 31,330 cells each), so metacell counts match across phenotypes.
- **Metacells:** SuperCell with `supercell.gamma_selected` (Astrocyte: `[60, 70, 80]`).
  SuperCell is not on conda; `workflow/envs/supercell.post-deploy.sh` installs it from GitHub
  (pinned commit) when Snakemake creates the env. Do not install packages inside scripts:
  parallel jobs race on the install and fail.
- **One gene set per cell type** (`aracne.genes`, rule `select_aracne_genes`,
  `results/aracne_genes/{cell_type}/genes.txt`), shared by every phenotype and gamma so the
  networks are comparable. Computed on single cells (not metacells, whose detection rate
  depends on gamma) of all phenotypes pooled:
  1. detected (count > 0) in >= 5% of cells (`min_frac_cells`)
  2. mitochondrial (`MT-`) and ribosomal (`RPL*/RPS*`) genes removed (`exclude_patterns`)
  3. the 4000 most variable genes (Seurat vst, `n_variable`)

  For Astrocyte: 36,601 -> 11,877 detected -> 11,784 after exclusion -> 4000 genes.
  `gene_selection.tsv` keeps the detection rate and standardized variance of every candidate.
- **ARACNe-AP:** every selected gene is a regulator, MI threshold p = 1E-8, 100 bootstraps
  (`aracne.bootstrap.n_boot`), then consolidation. Bootstrap networks are kept
  (`bootstrap_networks/`); only ARACNe's work folders are temporary.

### Cost

ARACNe's cost grows with the square of the number of genes. With ~12k genes one bootstrap
took ~10.5 h and ~21 GB; with 4000 genes it takes ~8-9 min and ~5.5 GB (see
`benchmarks/aracne/`). Bootstraps request 4 threads but use ~5-6 cores, so the real load is
higher than `--cores`. Memory per step is set in `aracne.memory` (Java gets `-Xmx` = memory - 2 GB);
if ARACNe hits `java.lang.OutOfMemoryError` it hangs instead of failing, so check
`grep OutOfMemory logs/aracne/*.log` when a bootstrap takes too long.

### Running on the server

```bash
# Check the job list first
snakemake -n --rerun-incomplete --until aracne_consolidate --use-conda

# Run (in tmux). --resources caps the memory of parallel jobs; --cores sets how many
# bootstraps run at once (cores / 4). Lower --cores if the server has a core limit.
snakemake --rerun-incomplete --until aracne_consolidate --use-conda \
    --cores 36 --resources mem_gb=300
```

The run can be stopped and relaunched with the same command: finished bootstraps are not
repeated, and `--rerun-incomplete` redoes the ones that were interrupted.
